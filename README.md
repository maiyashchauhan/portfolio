## 💻 Running Locally

To preview or run the portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/maiyashchauhan/portfolio.git
   cd portfolio
   ```

2. **Serve with Python HTTP Server:**
   ```bash
   python -m http.server 8000
   ```
   Open your browser and visit: `http://localhost:8000`

   *Alternatively, open `index.html` directly in your browser or use the VS Code Live Server extension.*
